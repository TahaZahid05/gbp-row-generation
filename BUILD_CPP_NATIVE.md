# C++ Native Solver Backend

This project includes a native C++ solver backend that eliminates PySCIPOpt's Python interpreter overhead.

## Prerequisites

- **OS**: Windows 10/11, x64
- **Compiler**: MSVC (Visual Studio Build Tools 2019/2022/2026)
- **SCIP**: SCIPOptSuite 10.x installed at `C:\Program Files\SCIPOptSuite 10.0.2`
- **Python**: 3.8+ (required for `os.add_dll_directory`)

### Install Visual Studio Build Tools (if not installed)

Download from: https://visualstudio.microsoft.com/visual-cpp-build-tools/

During installation, select **"Desktop development with C++"** workload.

From the project root:

gbp\build.bat

## How It Works

### Architecture

```
prym.py (Python)
  └── model_cpp.py (ctypes wrapper)
        └── solver.dll (C++ native, MSVC-compiled)
              ├── SCIP C API (libscip.dll)
              ├── Constraint handler (consEnfolp, consEnfops, consCheck, consLock)
              ├── BFS with distance caching
              └── On-demand coverage computation
```

### Key Components

1. **BFS Distance Computation** — cached per source vertex, computed on demand
2. **Row Generation** — violated covering constraints added as SCIP rows during LP solving
3. **Constraint Handler** — native SCIP callbacks, no Python overhead in B&B loop
4. **Warm-start** — BFF-d solution injected before solving
5. **Preseed Cuts** — initial covering constraints generated from BFF-d solution

### Runtime DLL Dependencies

`solver.dll` depends on:
- `libscip.dll` — from `C:\Program Files\SCIPOptSuite 10.0.2\bin`
- `MSVCP140.dll`, `VCRUNTIME140.dll` — MSVC runtime (pre-installed on Windows)

`model_cpp.py` adds the SCIP bin directory via `os.add_dll_directory()` before loading the DLL, so no manual PATH changes are needed.

## Fallback

If `solver.dll` is missing or fails to load:
```
[PRYM] C++ backend unavailable (...), falling back to Python
```

The pure Python `model.py` is used automatically — no code changes needed.

## Troubleshooting

### "cl is not recognized"

MSVC environment not initialized. The build script handles this automatically, but if it fails, run manually:

```cmd
"C:\Program Files (x86)\Microsoft Visual Studio\<year>\BuildTools\VC\Auxiliary\Build\vcvars64.bat"
gbp\build.bat
```

### "SCIP headers/lib not found"

Verify your SCIP installation path. Edit `gbp\build.bat` and update:
```bat
set SCIP_DIR=C:\Program Files\SCIPOptSuite 10.0.2
```

### "Could not find module solver.dll"

`libscip.dll` dependencies not found. Make sure `model_cpp.py` has:
```python
os.add_dll_directory(r"C:\Program Files\SCIPOptSuite 10.0.2\bin")
```

This must appear before `ctypes.CDLL(...)`.
